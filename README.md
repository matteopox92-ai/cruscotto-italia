# Cruscotto Economia Italia (Diplomacia)

Cruscotto dei conti della Repubblica Italiana per il governo: https://matteopox92-ai.github.io/cruscotto-italia/

- `dati/statistiche/` e `dati/cruscotto/`: letture del gioco (dal PC di Artos567 o dall'estensione degli aiutanti).
- `strumenti/`: script che costruiscono la pagina (`costruisci_cruscotto.py`, `cruscotto_offline.py`), controllano le letture e i conti.
- `.github/workflows/cruscotto.yml`: a ogni lettura nuova controlla i file, scarica il DEF, costruisce e pubblica la pagina.
